Geminiでは、**PDF・スライド・コード・文書・表計算などを生成し、チャット内で内容を確認して編集できます。** 「この一文だけ自分で直したい」「ここはAIに書き直してほしい」といった調整も、その場でできるのがうれしいところです。

Googleは2026年10月29日、こうしたファイルのプレビュー・編集機能を、無料の個人アカウントを含む全ユーザー向けに発表しました。

たとえば、スライドならレイアウトを見ながら文章を直し、コードなら生成された内容を直接修正できます。**今回発表されたプレビュー・編集機能は、PDFがWeb・モバイル対応、コードやスライドなどはWeb版対応**です。[Google公式発表](https://blog.google/innovation-and-ai/products/gemini-app/edit-files-directly/)

ただ、「コードやスライドって、前から作れなかった？」と思った方もいるかもしれません。そのとおりで、生成自体が今回初めて登場したわけではないんです。

この記事では、まず「何を作れるのか」「以前からできたことと今回の発表の違い」を整理して、そのあとPDF資料を使って操作の流れを見ていきます！

## 何ができる？ PDF・スライド・コードなどが対象

どんなものを作れるのか、使い方の例とあわせて見てみましょう。

| 作るもの                     | チャット内でできることの例                                                 |
| ---------------------------- | -------------------------------------------------------------------------- |
| PDF                          | 学習資料や説明資料を作り、プレビューしながら文章や図を修正する             |
| スライド                     | 発表資料を作り、レイアウトを確認して文章や構成を調整する                   |
| コード                       | コードを生成し、内容を確認して直接書き換えたり、修正を指示したりする       |
| Googleドキュメントなどの文書 | 下書きを作り、文章を直接編集したり、選択した部分の書き直しを依頼したりする |
| Googleスプレッドシート       | 管理表やデータ表を作り、プレビューしてGoogleスプレッドシートで開く         |
| Markdown・TXT・LaTeX         | テキストや数式を含む資料を作成・修正する                                   |

スライドは、Gemini内で調整してからGoogleスライドで開いたり、PPTXやPDFでダウンロードしたりできます。[Google Workspace公式の機能紹介](https://workspaceupdates.googleblog.com/2026/10/create-preview-and-edit-files-directly-in-the-Gemini-app.html)

## 以前からできたことと、今回の発表の違い

Geminiの作成・編集機能は、少しずつ追加されてきました。今回の発表がどこに当たるのか、これまでの流れを並べると分かりやすいです。

| 発表時期                   | 公式に案内された内容                                                                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2025年3月                  | Canvasで文書・コードを生成・編集。HTML・Reactなどのプレビューにも対応                                                                                                |
| 2025年10月                 | Canvasでスライドを生成し、Googleスライドへエクスポート                                                                                                               |
| 2026年4月                  | PDF・Word・Excelなど、各種ファイルをチャットから生成・ダウンロード                                                                                                   |
| **2026年10月29日（今回）** | **PDF・文書・スライド・表計算・コードなどについて、チャット内での生成・プレビュー・直接編集や、箇所を選んだ修正依頼を案内。PDFはWeb・モバイル、その他はWeb版が対象** |

出典：[Canvasの発表](https://blog.google/products-and-platforms/products/gemini/gemini-collaboration-features/)／[スライド生成の発表](https://workspaceupdates.googleblog.com/2025/10/generate-presentations-in-gemini-app.html)／[ファイル生成の発表](https://workspaceupdates.googleblog.com/2026/04/move-from-conversation-to-creation-with-file-generation-in-Gemini.html)／[今回の発表](https://blog.google/innovation-and-ai/products/gemini-app/edit-files-directly/)

今回注目したいのは、**生成したファイルを見ながら、自分で直す・Geminiに直してもらう、という作業をチャット内で進められること**です。全画面で直接入力したり、文章を選択して質問や修正を依頼したりする操作が紹介されています。

たとえばPDFなら、こんな流れで使えます。

1. 「初心者向けのPDF資料を作って」と依頼する
2. 生成された資料をプレビューする
3. 短い表現は自分で書き換える
4. 説明が難しい部分を選び、「もっと簡単に」とGeminiに頼む
5. 内容を確認し、PDFとして保存する

ここは少しややこしいのですが、従来のCanvasにも編集機能があります。コードの直接編集やプレビューも含めて「全部、今回初めてできるようになった！」というわけではない点は押さえておきましょう。

## 無料アカウントでも使える？ 特別な設定は必要？

**無料の個人Googleアカウントも対象です！** Googleは、Geminiアプリを利用できるすべてのユーザー・対応言語で提供すると案内しています。日本語でも使えます。

始め方は、いつものGeminiを開いて、欲しいファイルの形式を伝えるだけ。今回の機能を有効にするための特別な設定は案内されていません。

会社・学校のアカウントの場合は、組織でGeminiアプリを使えることが前提になります。[Google Workspace公式発表](https://workspaceupdates.googleblog.com/2026/10/create-preview-and-edit-files-directly-in-the-Gemini-app.html)

## PCとスマホでは、対応する形式が違う

使い始める前に、PCとスマホの違いも確認しておきましょう。今回発表された**プレビュー・編集機能**は、次の環境に対応しています。

| 形式                                       | PCのWeb版 | モバイル         |
| ------------------------------------------ | --------- | ---------------- |
| PDF                                        | 対応      | 対応             |
| コード                                     | 対応      | 今回の対応対象外 |
| スライド                                   | 対応      | 今回の対応対象外 |
| Googleドキュメント・Googleスプレッドシート | 対応      | 今回の対応対象外 |
| Markdown・TXT                              | 対応      | 今回の対応対象外 |

出典：[Google公式発表の対応環境](https://blog.google/innovation-and-ai/products/gemini-app/edit-files-directly/)

この表は、あくまでチャット内でのプレビュー・編集についてのものです。ファイルを生成できるかどうかとは分けて見てくださいね。ここからは、PCのブラウザ版を使う手順で紹介します。

## コードやスライドを作りたい場合の依頼例

PDF以外も、まずは「何を作りたいか」を具体的に伝えればOKです。たとえば、こんなふうに頼めます。

**コードを作って編集したい場合：**

```text
HTML・CSS・JavaScriptで、シンプルなToDoアプリを作成してください。
タスクの追加・完了・削除ができるようにしてください。
Gemini内で画面をプレビューし、コードを直接編集できる形にしてください。
```

**スライドを作って調整したい場合：**

```text
Webデザイン初心者向けに「美しいLPの作り方」という
タイトルで、5枚のスライドを作成してください。
構成は、導入・配色・余白・タイポグラフィ・まとめです。
チャット内でレイアウトを確認し、編集できる形にしてください。
```

生成されたら、「ボタンの色を青にして」「3枚目の説明を短くして」など、変えたいところを伝えてみましょう。ここからは、PDFを例に画面付きで見ていきます。

## 使い方：3ページのPDF資料を作ってみる

### 1. Geminiを開く

[Gemini](https://gemini.google.com/)を開き、Googleアカウントでログインします。

新しいチャットを開いたら、入力欄に「どんな内容を、何の形式で作ってほしいか」を書きましょう。[公式ヘルプの基本操作](https://support.google.com/gemini/answer/13275745?hl=en)

### 2. 作りたいPDFを指示する

まずは、次のプロンプトをそのまま貼り付けて試してみてください。ちなみにLPは、商品やサービスを紹介し、申し込みなどにつなげる「ランディングページ」のことです。

```text
Webデザイン初心者向けに、
「美しいLPの作り方」というタイトルのPDF資料を作成してください。

条件：
・日本語、A4縦、全3ページ
・1ページ目：配色の基本。ベースカラー・メインカラー・アクセントカラーの役割を説明
・2ページ目：余白の基本。要素を詰め込みすぎた例と、余白を整えた例を比較
・3ページ目：タイポグラフィの基本。見出し・本文の大きさや行間の使い分けを説明
・各ページに図または比較表を入れる
・専門用語には短い説明を添える

チャット内でプレビューできるPDFファイルとして作成してください。
```

「資料を作って」だけでも頼めますが、**誰向けか・どの形式か・どのくらいの量か・どんな構成か**まで伝えると、できあがったあとも確認しやすくなります。

もちろん、「3ページ」「図を入れる」と頼んだら、指定どおりになっているかも忘れずにチェックしましょう。

### 3. 生成されたファイルを開く

回答に表示されたファイルのプレビューやリンクから、生成物を開きます。

下の画面では、「美しいLPの作り方」というPDF資料を依頼すると、チャット内に編集可能なプレビューが表示されています。文章だけでなく、配色を説明する図も確認できます。

![PDF資料の作成を依頼し、Geminiのチャット内に図入りの資料プレビューが表示された画面](/images/gemini-file-preview-edit-guide/document-preview.png)
_プロンプトから生成された資料を、チャット内で確認できます。_

開いたら、まずはこの3つをチェックしてみてください。

- PDFを書き出せるプレビュー、またはPDFファイルが生成されているか
- 3ページに収まっているか
- 図表と日本語の文章が読みやすく表示されているか

もしファイルではなく文章だけが返ってきたら、続けてこんなふうに伝えてみてください。

```text
この内容を、ダウンロードできるPDFファイルとして作成してください。
```

公式ヘルプでも、欲しいファイル形式を明示して依頼する方法が案内されています。[ファイル生成の公式ヘルプ](https://support.google.com/gemini/answer/13275745?hl=en)

### 4. 内容を見ながら編集する

Googleの発表では、ファイルを全画面に広げて直接入力したり、文章を選択してGeminiに質問・修正を依頼したりできると説明されています。[編集操作の公式説明](https://blog.google/innovation-and-ai/products/gemini-app/edit-files-directly/)

ちょっとした言い換えは自分でサッと直して、説明の書き直しや図表の変更はGeminiにお任せする。そんな使い分けができそうです。

下の画面では、タイトルに「updated」、その下に「自由に書き込めちゃう！」と直接書き加えています。こんなふうに、プレビュー上でそのまま文章を直せるんです。

![Geminiの資料プレビューでタイトルと説明文を直接編集した画面。上部にはエクスポートメニューが表示されている](/images/gemini-file-preview-edit-guide/direct-edit.png)
_水色で示した部分が編集箇所です。編集した資料は、上部の「エクスポート」から書き出せます。_

「ちょっと説明が難しいな」と感じたら、その部分を選んで、こんなふうに頼んでみましょう。

```text
この説明を、Webデザインを初めて学ぶ人向けに書き直してください。
専門用語を減らし、身近な例を1つ加えてください。
```

図を直してほしいときも、どこを変えたいか具体的に伝えてみてください。

```text
2ページ目の余白の比較図を修正してください。
同じ文章とボタンを使い、余白の取り方だけを変えて、
違いが分かるようにしてください。
```

直してもらったら、その部分とあわせて、改ページや周りの配置も見ておきましょう。文章が長くなると、ページ数や図表の位置が変わることもあります。

### 5. 完成したファイルを保存する

いい感じに仕上がったら、ファイル画面からダウンロードやエクスポートの操作を確認しましょう。

掲載画面では、上部に**「エクスポート」**メニューがあります。PDFとして保存する場合は、このメニューを開いて書き出し形式を確認しましょう。

公式ヘルプによると、多くの形式では端末へのダウンロード、またはGoogle Driveへのエクスポートが可能です。表示された保存先・形式から、用途に合うものを選びましょう。[保存方法の公式ヘルプ](https://support.google.com/gemini/answer/13275745?hl=en)

誰かに配る前に、保存したPDFも一度開いておくと安心です。文字や図表が切れていないか、ページ数は合っているか、最後に確認しておきましょう。
